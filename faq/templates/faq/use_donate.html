Как пользоваться донат правами?

Открыть админь панель

  1. Нажмите на латинскую букву "M".
  2. Если админ панель не открылась, проверьте настройки игры и назначения клавиш.

Изменение роли

  1. Зайдите в Role Management.
  2. Выберите свой никнейм.
  3. Выберите роль, за которую хотите играть.
  4. Нажмите SET CLASS.

Выдача предметов

  1. Зайдите в Inventory.
  2. Выберите свой никнейм.
  3. Выберите предмет.
  4. Нажмите Grant item.

Выдача эффектов

  1. Зайдите в Status effects.
  2. Выберите свой никнейм.
  3. Нажмите на галочку.

Вызов отряда МОГ

  1. Зайдите в консоль администратора.
  2. Пропишите команду:
    wave spawn (ci или ntf)

Изменение размера

  1. Зайдите в консоль администратора.
  2. Пропишите команду:
    size me 0.7 0.7 0.7

Изменение цвета префикса

  1. Зайдите в консоль администратора.
  2. Пропишите команду:
    colortag set <название цветов>

Пример: colortag set pink red deep_pink
